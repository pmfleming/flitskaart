# Dutch spelling dictionary

`nl_NL.aff` and `nl_NL.dic` are OpenTaal's Hunspell dictionary for Dutch
(version 2.20.21, <https://github.com/OpenTaal/opentaal-hunspell>), copied
from LibreOffice's dictionaries repository. OpenTaal offers them under the
Revised BSD License and/or CC BY 3.0; see the header of `nl_NL.aff`.
